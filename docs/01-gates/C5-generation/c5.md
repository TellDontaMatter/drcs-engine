# C5 — Generation (Misalignment Protocol)

**Purpose:** LLM-based fresh caption generation when C4 escalation reaches here.

---

## Contract

**Input:** `{
  situation: string,
  content_type?: string,
  category?: string,
  tenant_id: string
}```

**Output:**  
`{
  action: 'GENERATED' | 'ESCALATE_FAILED',
  caption?: string,
  asset_recommendation?: string,
  reason: string
}```

---

## Acceptance Criteria

- `GENERATED` outcome includes fresh `caption` and optional `asset_recommendation`
- `ESCALATE_FAILED` when LLM unreachable, empty situation, or empty response
- Prompt construction embeds `situation`, `content_type`, `category` when available
- LLM response parsing handles: clean JSON, JSON in code fences, plain text fallback
- No actual LLM calls in tests (mocked via `jest.spyOn(llm, 'callLLM')`)
