# C6 — Governance

**Purpose:** Message-Idea disposition: decide PUBLISH / REJECT / HOLD / REROUTE for every trigger.

---

## Contract

**Input:** `trigger: {
  condition: string,
  confidence_tag?,
  stakes?,
  allowed_to_acknowledge?: string[],
  must_not_presume?: string[]
}, tenant_id`

**Output:**  
`{
  disposition: 'PUBLISH' | 'REJECT_AND_RECORD' | 'HOLD_FOR_HUMAN_REVIEW' | 'REROUTE_FOR_RECLASSIFICATION',
  record: GovernanceRecord
}```

---

## Acceptance Criteria

- All four dispositions reachable from distinct inputs
- **No silent downgrade:** `REJECT` and `HOLD` precedence preserved (never downgraded to `PUBLISH`)
- `allowed_to_acknowledge` and `must_not_presume` populate descriptive fields (never null)
- Every trigger creates a `GovernanceRecord` (queryable history)
- Disposition-filtered queries work (e.g., `listRecords(tenant_id, { disposition: 'REJECT' })`)
- Tenant isolation verified
