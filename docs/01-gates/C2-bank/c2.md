# C2 — Situational Bank

**Purpose:** Resolve a situational category from a real-time condition signal. No date/calendar selection path.

---

## Contract

**Input:** `condition_signal: { category_id?, situation? }`, `tenant_id`

**Output:**  
`{
  category_id: string | null,
  available_assets: string[],
  matched: boolean,
  protected: boolean,
  prestocked: boolean,
  reason: string
}```

---

## Acceptance Criteria

- Explicit `category_id` wins (exact match)
- `situation` label matches category name (case-insensitive)
- No match → returns `matched: false` with reason
- **CRITICAL:** Zero date/calendar/weekday logic. Static source scan test confirms no `Date()`, `getDay()`, calendar APIs in compiled output.
- Protected category (e.g., 'Friday') resolved from signal is returned as-is with `protected: true`
- Tenant isolation verified
