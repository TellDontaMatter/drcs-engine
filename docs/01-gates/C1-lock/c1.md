# C1 — Lock

**Purpose:** Enforce single-use content by sealing assets after first deployment.

---

## Contract

**Input:** `asset_id`, `tenant_id`

**Output:**  
`allowed: boolean` (true if asset is unsealed/reusable, false if locked)

---

## Acceptance Criteria

- Unsealed assets pass validation
- Sealed (locked) assets fail validation
- Multi-tenant isolation: tenant A cannot validate tenant B's assets
- Sealing is idempotent (calling seal() twice is safe)
