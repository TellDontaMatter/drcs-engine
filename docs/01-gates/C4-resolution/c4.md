# C4 — Resolution

**Purpose:** Caption-first 3-step ladder: find reusable content before escalating to fresh generation.

---

## Contract

**Input:** `category_id`, `content_need: { caption, exclude_asset_ids?, required_tag? }`, `tenant_id`

**Output:**  
`{
  step: 'EXISTING_AS_IS' | 'RECAPTION' | 'ESCALATE_TO_C5',
  asset_id: string | null,
  caption: string | null,
  reason: string,
  caption_source?: 'AS_IS' | 'RECAPTIONED'
}```

---

## Acceptance Criteria

- **Step 1 (Existing-as-is):** Exact caption match in resolved category → returns asset + caption, `step: EXISTING_AS_IS`, `caption_source: AS_IS`
- **Step 2 (Recaption):** No exact match but assets available → returns first non-excluded asset + new caption, `step: RECAPTION`, `caption_source: RECAPTIONED`
- **Step 3 (Escalate):** No assets available → returns `step: ESCALATE_TO_C5`, `asset_id: null`, `caption: null`
- Respects `exclude_asset_ids` and `required_tag` filters
- Caption normalization (whitespace, case-insensitive) for matching
- Throws `CategoryNotFoundError` if category doesn't exist
- Tenant isolation verified
