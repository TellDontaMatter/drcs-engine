# C3 — Governor

**Purpose:** Enforce rolling frequency cap: max 3 deployments per asset per 30-day window per deployment instance.

---

## Contract

**Input:** `asset_id`, `tenant_id`, `max_count?`, `rolling_window_days?`, `now?` (for deterministic testing)

**Output:**  
`{
  allowed: boolean,
  current_count: number,
  failed_closed: boolean,
  reason: string
}```

---

## Acceptance Criteria

- Allows deployment when count < max_count (3)
- Blocks when count >= max_count within rolling window
- Rolling window excludes deployments older than 30 days
- **Fail-closed:** If usage log integrity cannot be verified, blocks deployment (`failed_closed: true`)
- Tenant isolation verified
- Locked params: `max_count=3`, `rolling_window=30 days`, `counting_unit=per deployment instance`
